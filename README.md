A feed forward network is a collection of neurons that are connected to each other allowing for information to path through. 
Each layer of neurons that is fully connected to the previous layer is known as a dense layer
For each path through the network is knwon as an epoch

To train the network we must first give it some training data where we know what the output should be. 
Every time the netowrk gives an output we compare it to the expected output. If the outputted answer matches the expected output we leave the weights and the threshold alone else we adjust the so that we gain the expected output
After training we test the network
